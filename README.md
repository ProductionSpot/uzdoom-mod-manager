## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **WAD Library** | Organize all your Doom WAD files and mods with metadata |
| **Load Config** | Build named mod load lists with drag-to-reorder priority |
| **IWAD Selector** | Choose the base IWAD per configuration from a dropdown |
| **Quick Launch** | Launch UZDoom with any saved load configuration in one click |
